# 自底向上架构优化方案

## 📐 设计理念

采用**自底向上**的开发模式，从底层基础设施开始构建，确保每层独立可测试、可替换、可扩展。

```
┌─────────────────────┐
│    Views (页面层)     │  ← 用户界面
├─────────────────────┤
│ Components (组件层) │  ← UI组件
├─────────────────────┤
│ Composables (逻辑层) │  ← 业务逻辑
├─────────────────────┤
│   Store (状态层)     │  ← 状态管理
├─────────────────────┤
│  Services (服务层)   │  ← API调用
├─────────────────────┤
│   Utils (工具层)     │  ← 基础工具
├─────────────────────┤
│   Types (类型层)     │  ← 类型定义
└─────────────────────┘
```

## 🔧 优化原则

1. **依赖倒置**：上层依赖下层，下层不依赖上层
2. **接口隔离**：每层提供清晰接口，隐藏实现细节
3. **单一职责**：每层专注单一职责
4. **开闭原则**：对扩展开放，对修改封闭
5. **类型驱动**：TypeScript类型优先

## 🏗️ 架构说明

### Services层架构选择：单体 vs 模块化

**当前采用单体服务架构**：

- 每个业务域对应一个独立的服务文件
- 继承统一的 `BaseApiService`
- 在 `services/index.ts` 中统一导出

**模块化的层级**：

- **API配置层**：`config/api/modules/` - 模块化API配置
- **状态管理层**：`store/modules/` - 模块化状态管理

**设计原因**：

1. **简化复杂度**：避免服务层过度抽象
2. **便于维护**：相关API集中管理
3. **类型安全**：每个服务文件可独立类型定义
4. **灵活扩展**：新增服务只需创建新文件

**基于 topic-selection 功能的调用链**：

### 异步任务处理标准

**统一模式**：

```typescript
// 1. 创建任务
const taskId = await service.createTask(params)

// 2. 启动轮询
const poller = new AsyncTaskPoller(() => service.getTaskStatus(taskId), {
  interval: 2000,
  timeout: 120000
})

// 3. 监听事件
poller.on('progress', (status) => updateProgress(status))
poller.on('completed', (result) => handleResult(result))

// 4. 启动
const task = await poller.start(taskId)
```

**状态管理**：

```typescript
// 状态定义
const currentTask = ref<PollingTask | null>(null)
const taskStatus = ref<TaskStatus | null>(null)
const isLoading = ref(false)

// 操作方法
const executeTask = async (params: any) => {
  isLoading.value = true
  try {
    const poller = await service.executeWithPolling(params)
    poller.on('progress', (status) => (taskStatus.value = status))
    currentTask.value = poller
  } finally {
    isLoading.value = false
  }
}
```

#### 3️⃣ 服务组合与工厂模式

**服务工厂**：

```typescript
// src/services/core/ServiceFactory.ts
export class ServiceFactory {
  private static instances: Map<string, any> = new Map()

  static create<T>(ServiceClass: new () => T): T {
    const className = ServiceClass.name
    if (this.instances.has(className)) {
      return this.instances.get(className)
    }
    const instance = new ServiceClass()
    this.instances.set(className, instance)
    return instance
  }

  // 创建模块服务组合
  static createTopicSelectionModule() {
    return {
      service: ServiceFactory.create(TopicSelectionService),
      scopeAgent: ServiceFactory.create(ScopeAgentService),
      searchAgent: ServiceFactory.create(SearchAgentService)
    }
  }

  static createOutlineModule() {
    return {
      service: ServiceFactory.create(OutlineGenerationService),
      titleAgent: ServiceFactory.create(TitleAgentService),
      outlineAgent: ServiceFactory.create(OutlineAgentService),
      search2TitleAgent: ServiceFactory.create(Search2TitleAgentService)
    }
  }

  static createContentModule() {
    return {
      service: ServiceFactory.create(ContentGenerationService),
      materialBind: ServiceFactory.create(MaterialBindService),
      bodyAgent: ServiceFactory.create(BodyAgentService),
      aiText: ServiceFactory.create(AITextService)
    }
  }
}
```

**模块化工作流**：

```typescript
// src/services/workflows/DocumentGenerationWorkflow.ts
export class DocumentGenerationWorkflow {
  private topicSelection = ServiceFactory.createTopicSelectionModule()
  private outline = ServiceFactory.createOutlineModule()
  private content = ServiceFactory.createContentModule()

  // 完整文档生成流程
  async generateDocument(params: {
    userId: string
    projectId: string
    brief: string
    webSearchData?: any[]
    selectedTitle?: any
  }) {
    // 阶段1：主题选择
    const scopeResult = await this.topicSelection.service.executeScopeOnly(...)

    // 阶段2：大纲生成
    const titleResult = await this.outline.service.generateTitles(...)

    let outlineResult = null
    if (params.selectedTitle) {
      outlineResult = await this.outline.service.generateOutline(...)
    }

    // 阶段3：正文生成（可选）
    let contentResult = null
    if (outlineResult) {
      contentResult = await this.content.service.generateContent(...)
    }

    return { scope: scopeResult, titles: titleResult, outline: outlineResult, content: contentResult }
  }
}
```

**收益**：

- 服务复用性提升
- 工作流编排灵活
- 服务依赖管理清晰
- 支持动态服务组合

**服务缓存**：

```typescript
// src/services/core/ServiceCache.ts
export class ServiceCache {
  private cache = new Map<string, { data: any; timestamp: number }>()
  private ttl = 5 * 60 * 1000 // 5分钟

  set(key: string, data: any): void {
    this.cache.set(key, { data, timestamp: Date.now() })
  }

  get<T>(key: string): T | null {
    const item = this.cache.get(key)
    if (!item) return null
    if (Date.now() - item.timestamp > this.ttl) {
      this.cache.delete(key)
      return null
    }
    return item.data
  }
}
```
