## 🎯 核心目录说明

### 1️⃣ 表示层 (Presentation Layer)

**职责**: UI展示、用户交互

**目录**:

- `src/views/` - 页面级组件（路由对应页面）
- `src/components/` - 可复用组件
- `src/composables/` - 组合式函数（逻辑复用）

**开发重点**:

- 组件职责单一
- Props和Emits类型定义
- 业务逻辑提取到Composables

---

### 2️⃣ 业务逻辑层 (Business Logic Layer)

**职责**: 业务规则处理、状态管理

**目录**:

- `src/store/` - Pinia状态管理
- `src/services/` - API服务层

**开发重点**:

- Store管理状态，Service调用API
- 异步操作在action中处理
- 状态变化可预测

---

### 3️⃣ 数据访问层 (Data Access Layer)

**职责**: 数据获取、存储管理

**目录**:

- `src/utils/http/` - HTTP客户端
- `src/utils/storage/` - 本地存储
- `src/utils/polling/` - 轮询机制
- `src/mock/` - Mock数据

**开发重点**:

- 统一HTTP请求处理
- 统一的错误处理机制
- 缓存策略明确

---

### 4️⃣ 基础设施层 (Infrastructure Layer)

**职责**: 类型定义、配置管理

**目录**:

- `src/types/` - TypeScript类型
- `src/config/` - 配置文件
- `src/utils/` - 工具函数
- `src/router/` - 路由配置
- `src/locales/` - 国际化

**开发重点**:

- 类型定义集中管理
- 配置外部化
- 工具函数模块化

## 🚀 快速开始开发

### 1. 新增一个功能模块

```bash
# 1. 创建页面
touch src/views/[module]/[Feature]View.vue

# 2. 创建组件
touch src/components/custom/[module]/[Feature].vue

# 3. 创建服务
touch src/services/[feature]Service.ts

# 4. 创建类型
touch src/types/[feature].ts

# 5. 创建状态
touch src/store/[feature].ts

# 6. 创建组合式函数
touch src/composables/use[Feature].ts
```

### 2. 典型开发流程

```mermaid
graph LR
    A[创建类型定义] --> B[实现API服务]
    B --> C[管理状态]
    C --> D[编写组合式函数]

    E --> F[创建页面]
```
