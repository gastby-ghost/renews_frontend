## 开发任务与文件映射

### 新增一个页面

1. **创建页面组件**

   - `src/views/[模块]/[页面]View.vue`

2. **添加路由配置**

   - `src/router/index.ts`

3. **创建状态管理（如果需要）**

   - `src/store/[模块].ts`

4. **创建服务（如果需要）**

   - `src/services/[模块]Service.ts`

5. **添加类型定义**
   - `src/types/[模块].ts`

**示例**：

```bash
# 新增用户管理页面
src/views/user/UserManagementView.vue
src/store/user.ts
src/services/userService.ts
src/types/user.ts
src/router/index.ts
```

---

### 新增一个组件

1. **创建组件文件**

   - `src/components/custom/[业务域]/[组件名].vue`

2. **定义Props和Emits**

   - 使用TypeScript严格类型

3. **提取逻辑到Composables（如果复杂）**
   - `src/composables/useXxx.ts`

**示例**：

```bash
# 新增素材卡片组件
src/components/custom/material/MaterialCard.vue
src/composables/useMaterialCard.ts  # 如果逻辑复杂
```

---

### 新增API服务

1. **继承BaseApiService**

   - `src/services/[模块]Service.ts`

2. **定义API方法**

   - 使用泛型返回类型

3. **实现Mock方法**

   - `src/services/[模块]Service.ts` - `mockImplementation`

4. **添加到状态管理**
   - `src/store/[模块].ts`

**示例**：

```typescript
// src/services/materialService.ts
export class MaterialService extends BaseApiService {
  protected basePath = '/materials'

  async search(params: SearchParams): Promise<ApiResponse<Material[]>> {
    return this.get('/search', params)
  }

  protected mockImplementation(config: ApiRequestConfig): Promise<any> {
    // Mock实现
  }
}
```

---

### 状态管理操作

1. **定义State**

   ```typescript
   const materials = ref<Material[]>([])
   const loading = ref(false)
   ```

2. **定义Actions**

   ```typescript
   const fetchMaterials = async () => {
     loading.value = true
     try {
       const result = await materialService.getList()
       materials.value = result.data
     } finally {
       loading.value = false
     }
   }
   ```

3. **返回响应式数据**
   ```typescript
   return {
     materials,
     loading,
     fetchMaterials
   }
   ```

## 核心开发原则

### 1. 📐 分层架构

**原则**：每层只关注自己的职责

- **表示层**（Views/Components）→ UI展示、用户交互
- **业务逻辑层**（Composables/Store）→ 业务规则、数据处理
- **服务层**（Services）→ API调用、数据获取
- **基础设施层**（Utils/Types）→ 工具、类型、配置

**实践**：

- 组件不直接调用API
- 服务不直接操作DOM
- 状态变化可预测

---

### 2. 🔄 单向数据流

```
用户操作 → 组件事件 → Composable → Store Action → API服务 → 更新状态 → UI响应
```

**实践**：

- 状态只能通过Store action修改
- 组件通过computed响应状态变化
- 避免直接修改store状态

---

### 3. 🎯 单一职责

**组件**：只负责UI渲染和用户交互 **服务**：只负责单一业务领域的API调用 **工具函数**：只负责一个功能点 **类型定义**：只描述一个数据模型

---

### 4. 📝 TypeScript优先

- 所有文件必须使用TypeScript
- 严格类型检查
- 泛型使用
- 类型守卫

## 常用开发场景

### 场景1：实现用户登录功能

**涉及文件**：

1. `src/types/user.ts` - 定义用户类型
2. `src/services/authService.ts` - 实现登录API
3. `src/store/user.ts` - 管理登录状态
4. `src/composables/useAuth.ts` - 封装登录逻辑
5. `src/views/auth/LoginView.vue` - 登录页面

**开发步骤**：

```typescript
// 1. 定义类型
// src/types/user.ts
interface LoginCredentials {
  email: string
  password: string
  remember_me: boolean
}

// 2. 实现服务
// src/services/authService.ts
export class AuthService extends BaseApiService {
  async login(credentials: LoginCredentials): Promise<ApiResponse<AuthResponse>> {
    return this.post('/auth/login', credentials)
  }
}

// 3. 管理状态
// src/store/user.ts
export const useUserStore = defineStore('user', () => {
  const isLogin = ref(false)
  const userInfo = ref<UserInfo | null>(null)

  const login = async (credentials: LoginCredentials) => {
    const response = await authService.login(credentials)
    isLogin.value = true
    userInfo.value = response.data.user
  }

  return { isLogin, userInfo, login }
})

// 4. 封装逻辑
// src/composables/useAuth.ts
export const useAuth = () => {
  const userStore = useUserStore()
  const router = useRouter()

  const login = async (credentials: LoginCredentials) => {
    try {
      await userStore.login(credentials)
      router.push('/dashboard')
    } catch (error) {
      // 错误处理
    }
  }

  return { login }
}

// 5. 页面使用
// src/views/auth/LoginView.vue
const { login } = useAuth()
const handleSubmit = (credentials: LoginCredentials) => {
  login(credentials)
}
```

### 场景2：实现素材搜索功能

**涉及文件**：

1. `src/types/material.ts` - 素材类型
2. `src/services/materialService.ts` - 搜索API
3. `src/store/material.ts` - 搜索状态
4. `src/composables/useMaterialSearch.ts` - 搜索逻辑
5. `src/components/custom/material/MaterialSearch.vue` - 搜索组件
6. `src/components/custom/material/MaterialList.vue` - 结果列表

**开发步骤**：

```typescript
// 1. 类型定义
// src/types/material.ts
interface Material {
  id: string
  title: string
  thumbnail: string
  // ...
}

interface SearchFilters {
  category?: string
  source?: string
}

// 2. 服务实现
// src/services/materialService.ts
export class MaterialService extends BaseApiService {
  async search(query: string, filters?: SearchFilters): Promise<ApiResponse<Material[]>> {
    return this.get('/materials/search', { query, ...filters })
  }
}

// 3. 状态管理
// src/store/material.ts
export const useMaterialStore = defineStore('material', () => {
  const materials = ref<Material[]>([])
  const loading = ref(false)
  const error = ref<string | null>(null)

  const searchMaterials = async (query: string, filters?: SearchFilters) => {
    loading.value = true
    error.value = null
    try {
      const result = await materialService.search(query, filters)
      materials.value = result.data
    } catch (e) {
      error.value = e.message
    } finally {
      loading.value = false
    }
  }

  return { materials, loading, error, searchMaterials }
})

// 4. 组合式函数
// src/composables/useMaterialSearch.ts
export const useMaterialSearch = () => {
  const materialStore = useMaterialStore()
  const debouncedSearch = useDebounceFn((query: string, filters?: SearchFilters) => {
    materialStore.searchMaterials(query, filters)
  }, 300)

  return {
    materials: readonly(materialStore.materials),
    loading: readonly(materialStore.loading),
    error: readonly(materialStore.error),
    search: debouncedSearch
  }
}

// 5. 组件使用
// src/components/custom/material/MaterialSearch.vue
const { search } = useMaterialSearch()
const handleSearch = (query: string) => {
  search(query)
}
```

### 场景3：实现异步任务轮询

**涉及文件**：

1. `src/utils/polling/asyncTaskPoller.ts` - 轮询器
2. `src/store/polling.ts` - 轮询状态
3. `src/services/documentGenerateService.ts` - 任务API

**开发步骤**：

```typescript
// 1. 使用轮询器
// src/store/documentGenerate.ts
export const useDocumentStore = defineStore('document', () => {
  const pollingStore = usePollingStore()

  const executeAgent = async (taskId: string) => {
    pollingStore.startPolling(taskId, {
      interval: 2000,
      timeout: 120000,
      maxAttempts: 60
    })

    const poller = new AsyncTaskPoller()
    const result = await poller.poll(
      taskId,
      {
        interval: 2000,
        timeout: 120000
      },
      (id) => checkTaskStatus(id)
    )

    return result
  }

  const checkTaskStatus = async (taskId: string): Promise<TaskStatus> => {
    const response = await documentService.getTaskStatus(taskId)
    return response.data.status
  }

  return { executeAgent }
})
```
