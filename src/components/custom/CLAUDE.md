# Custom Components

业务定制组件目录，包含项目中使用的所有业务特定 UI 组件。

## Directory Structure

| Folder                                | Description      |
| ------------------------------------- | ---------------- |
| [material-card/](./material-card)     | 素材卡片相关组件 |
| [comment-widget/](./comment-widget)   | 评论组件         |
| [search-progress/](./search-progress) | 搜索进度展示组件 |
| [document/](./document)               | 文档生成相关组件 |
| [material-search/](./material-search) | 素材搜索组件     |

## Components

- `TitleEditDialog.vue` - 标题编辑对话框
- `TitleCard.vue` - 标题卡片组件
- `StepIndicator.vue` - 步骤指示器
