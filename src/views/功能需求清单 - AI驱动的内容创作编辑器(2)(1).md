# AI驱动的内容创作编辑器功能需求清单

## 功能模块归类

### 用户登录模块

这个模块构成了用户身份验证和账户管理的基础流程，用户必须通过此模块才能使用系统。

#### 0. 用户登录模块

- F038\_用户注册：创建新用户账户
- F039\_用户登录：用户身份验证
- F040\_忘记密码：密码重置流程
- F041\_第三方登录：第三方平台身份验证
- F042\_账户设置：账户信息管理

### 核心创作流程模块

这些模块构成了内容创作的主要工作流程，用户将按照这个流程依次完成内容创作。

#### 1. 需求定义模块

- F006\_需求定义：定义内容创作的需求参数
- F007\_需求模板保存：保存需求定义为模板
- F008\_需求模板应用：应用已保存的需求模板
- F009\_需求模板管理：管理需求模板

#### 2. 标题生成模块

- F043\_标题素材区：管理用于标题生成的素材
- F044_AI自动检索素材：AI自动检索主流媒体素材
- F045\_手动选择素材：手动选择素材并设置检索条件
- F010\_标题生成：基于需求生成标题选项
- F011\_素材绑定到标题：将素材绑定到标题生成
- F012\_标题选择：选择或编辑最终标题
- F013\_标题分析：分析标题质量

#### 3. 大纲结构模块

- F014\_大纲结构管理：创建和编辑文章大纲
- F015\_章节预览：预览章节内容
- F016\_素材绑定到章节：将素材绑定到章节
- F017\_大纲AI优化：使用AI优化大纲结构

#### 4. 正文编辑模块

- F024\_正文编辑：编辑文章正文内容
- F025_AI辅助编辑：使用AI辅助文本编辑
- F026_AI对话：与AI助手对话并修改内容
- F027\_初稿生成：基于大纲生成文章初稿

### 辅助功能模块

这些模块为核心创作流程提供支持和服务。

#### 5. 项目/文件夹管理模块

- F001\_项目创建：创建新的内容创作项目
- F002\_项目列表管理：显示和管理所有项目

- F004\_文件夹管理：创建和管理文件夹

#### 6. 素材管理模块

#### 7. AI辅助功能模块

#### 8. 成稿导出模块

- F030\_成稿导出：导出完成的文稿

#### 9. 写作统计模块

- F031\_写作统计：显示写作统计数据
- F032\_报告导出：导出写作分析报告

#### 10. 组件导航模块

## 0. 用户登录模块

### F038\_用户注册

| **字段** | **内容** |
| --- | --- |
| **功能ID** | F038\_用户注册 |
| **功能描述** | 允许新用户创建账户，包含邮箱验证和密码安全要求 |
| **用户故事** | As a 新用户, I want to 注册账户, so that 使用AI内容创作编辑器 |
| **功能优先级** | Must have（核心功能） |
| **业务规则** | 1. 用户名必须唯一且3-20个字符 2. 密码必须包含大小写字母、数字和特殊字符，至少8位 3. 邮箱必须有效且需验证 4. 同一邮箱只能注册一个账户 |
| **前置条件** | 用户访问注册页面 |
| **后置条件** | 用户账户创建成功，发送验证邮件，跳转到登录页面 |
| **交互流程** | 1. 访问注册页面 2. 填写用户名、邮箱、密码 3. 阅读并同意服务条款 4. 点击"注册"按钮 5. 系统验证信息 6. 发送验证邮件 7. 提示用户查收邮件 |
| **异常处理** | - 用户名已存在 → 提示"该用户名已被使用" - 邮箱已注册 → 提示"该邮箱已注册" - 密码不符合要求 → 提示"密码必须包含大小写字母、数字和特殊字符，至少8位" - 验证邮件发送失败 → 提示"验证邮件发送失败，请稍后重试" |
| **数据输入** | - 用户名（string，3-20字符，必填） - 邮箱（string，有效邮箱格式，必填） - 密码（string，符合复杂度要求，必填） - 确认密码（string，必填） - 服务条款同意（boolean，必填） |
| **数据输出** | 注册成功提示 + 验证邮件发送状态 |
| **关联功能** | 用户登录（F039）、忘记密码（F040） |

### F039\_用户登录

| **字段** | **内容** |
| --- | --- |
| **功能ID** | F039\_用户登录 |
| **功能描述** | 允许已注册用户通过用户名/邮箱和密码登录系统 |
| **用户故事** | As a 注册用户, I want to 登录系统, so that 访问我的创作项目和内容 |
| **功能优先级** | Must have（核心功能） |
| **业务规则** | 1. 支持用户名或邮箱登录 2. 密码错误超过5次锁定账户30分钟 3. 记住登录功能有效期7天 4. 登录后跳转到上次访问页面或项目列表 |
| **前置条件** | 用户访问登录页面 |
| **后置条件** | 用户身份验证成功，创建会话，跳转到系统主页 |
| **交互流程** | 1. 访问登录页面 2. 输入用户名/邮箱和密码 3. 选择"记住登录"（可选） 4. 点击"登录"按钮 5. 系统验证凭据 6. 登录成功跳转 |
| **异常处理** | - 用户不存在 → 提示"用户名或邮箱不存在" - 密码错误 → 提示"密码错误，剩余尝试次数：X" - 账户锁定 → 提示"账户已锁定，请30分钟后再试" - 邮箱未验证 → 提示"请先验证您的邮箱" |
| **数据输入** | - 用户名/邮箱（string，必填） - 密码（string，必填） - 记住登录（boolean，可选） |
| **数据输出** | 登录状态 + 会话令牌 + 跳转页面 |
| **关联功能** | 用户注册（F038）、忘记密码（F040）、第三方登录（F041） |

### F040\_忘记密码

| **字段** | **内容** |
| --- | --- |
| **功能ID** | F040\_忘记密码 |
| **功能描述** | 允许用户通过注册邮箱重置密码 |
| **用户故事** | As a 注册用户, I want to 重置密码, so that 恢复账户访问权限 |
| **功能优先级** | Must have（核心功能） |
| **业务规则** | 1. 重置链接有效期24小时 2. 新密码必须符合复杂度要求 3. 重置后所有现有会话失效 4. 同一邮箱5分钟内只能请求一次重置 |
| **前置条件** | 用户点击"忘记密码"链接 |
| **后置条件** | 密码重置链接发送到用户邮箱，或密码成功更新 |
| **交互流程** | 1. 点击"忘记密码"链接 2. 输入注册邮箱 3. 点击"发送重置链接" 4. 查收邮件并点击重置链接 5. 输入新密码和确认密码 6. 点击"重置密码" 7. 密码更新成功 |
| **异常处理** | - 邮箱未注册 → 提示"该邮箱未注册" - 重置链接无效 → 提示"重置链接无效或已过期" - 新密码不符合要求 → 提示"密码必须包含大小写字母、数字和特殊字符，至少8位" - 重置失败 → 提示"密码重置失败，请重试" |
| **数据输入** | - 邮箱（string，必填） - 新密码（string，符合复杂度要求，必填） - 确认密码（string，必填） - 重置令牌（string，必填） |
| **数据输出** | 重置链接发送状态或密码更新状态 |
| **关联功能** | 用户登录（F039）、用户注册（F038） |

### F041\_第三方登录

| **字段** | **内容** |
| --- | --- |
| **功能ID** | F041\_第三方登录 |
| **功能描述** | 支持通过Google、Microsoft、GitHub等第三方平台登录系统 |
| **用户故事** | As a 用户, I want to 使用第三方账户登录, so that 快速访问系统无需记住新密码 |
| **功能优先级** | Should have（重要功能） |
| **业务规则** | 1. 支持OAuth 2.0标准协议 2. 首次使用第三方登录需绑定邮箱 3. 第三方账户只能绑定一个系统账户 4. 可在账户设置中解除绑定 |
| **前置条件** | 用户访问登录页面 |
| **后置条件** | 用户通过第三方身份验证成功，创建或关联系统账户 |
| **交互流程** | 1. 在登录页面点击第三方平台图标 2. 跳转到第三方授权页面 3. 用户授权应用访问 4. 系统获取用户信息 5. 首次使用需补充邮箱信息 6. 登录成功跳转 |
| **异常处理** | - 授权失败 → 提示"第三方授权失败，请重试" - 账户已绑定 → 提示"该第三方账户已绑定其他用户" - 邮箱冲突 → 提示"该邮箱已注册，请使用密码登录" |
| **数据输入** | - 第三方平台（string，必填：Google/Microsoft/GitHub） - 授权令牌（string，必填） - 邮箱（string，首次使用时必填） |
| **数据输出** | 登录状态 + 会话令牌 + 跳转页面 |
| **关联功能** | 用户登录（F039）、账户设置（F042） |
