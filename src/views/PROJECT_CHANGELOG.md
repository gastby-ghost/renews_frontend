# @renews_frontend/ 项目变更记录

## 📋 项目概述

**项目名称**: Art Design Pro (renews_frontend)  
**项目版本**: 0.0.0  
**创建时间**: 2025年9月11日  
**最后更新**: 2025年9月11日

这是一个基于 Vue 3 + Element Plus 的现代化管理后台系统，专注于用户体验和快速开发。

## 📊 项目统计

- **总文件数**: 106+ Vue 组件
- **主要模块**: 15个
- **组件库**: 91+ 个组件
- **工具函数**: 36+ 个

## 🏗️ 项目架构

### 核心技术栈

- **前端框架**: Vue 3.5.12
- **UI 组件库**: Element Plus 2.10.2
- **状态管理**: Pinia 3.0.2
- **路由管理**: Vue Router 4.4.2
- **构建工具**: Vite 6.1.0
- **语言支持**: TypeScript 5.6.3

### 目录结构

```
src/views/
├── article/           # 文章管理模块
├── auth/             # 用户认证模块
├── dashboard/        # 仪表板模块
├── document-generation/ # 文档生成模块 (AI驱动)
├── material/         # 素材管理模块
├── system/          # 系统管理模块
├── widgets/         # 组件库展示
└── ...
```

## 🔄 自动同步机制

### Git Hook 集成

项目已集成以下自动化工具：

- **Husky**: Git hooks 管理

- **Lint-staged**: 提交前代码检查

### 提交规范

使用 Conventional Commits 规范：

- `feat:` 新功能
- `fix:` 修复
- `docs:` 文档更新
- `style:` 样式调整
- `refactor:` 重构
- `test:` 测试
- `chore:` 构建/工具链
