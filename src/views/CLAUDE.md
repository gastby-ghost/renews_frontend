# Views Directory

页面组件目录，包含应用中所有页面的视图组件。

## Directory Structure

| Folder                                        | Description              |
| --------------------------------------------- | ------------------------ |
| [document-generation/](./document-generation) | 文档生成流程页面         |
| [material/](./material)                       | 素材管理页面             |
| [auth/](./auth)                               | 认证相关页面             |
| [user/](./user)                               | 用户相关页面             |
| [exception/](./exception)                     | 异常页面 (403, 404, 500) |
| [outside/](./outside)                         | 外部页面                 |

## Root Files

| File              | Description |
| ----------------- | ----------- |
| `index/index.vue` | 首页        |
