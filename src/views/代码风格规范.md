## 📁 文件组织

每个组件遵循以下文件结构：

```
ComponentName/
├── ComponentName.vue     # 主组件文件
├── index.ts             # 导出文件
└── ComponentName.test.vue (可选) # 测试文件
```

### 导出文件规范 (index.ts)

```typescript
export { default as ComponentName } from './ComponentName.vue'
export type { ComponentNameProps } from './ComponentName.vue'
```

## 🔤 TypeScript规范

### Props接口定义

```typescript
export interface ComponentNameProps {
  // 必需属性在前
  modelValue?: string | number

  // 可选属性按逻辑分组
  variant?: 'primary' | 'secondary' | 'accent' | 'success' | 'warning' | 'error' | 'info'
  size?: 'sm' | 'md' | 'lg'

  // 布尔属性
  disabled?: boolean
  loading?: boolean
  readonly?: boolean

  // 功能属性
  placeholder?: string
  maxLength?: number
}
```

### 核心规范

1. **联合类型** - 使用字符串字面量定义变体
2. **可选属性** - 提供合理默认值
3. **类型严格** - 明确定义所有Props和事件类型

### 默认值定义

```typescript
const props = withDefaults(defineProps<ComponentNameProps>(), {
  variant: 'primary',
  size: 'md',
  disabled: false
})
```

### CSS样式规范

```css
/* ❌ 禁止使用 @apply 指令 */
.button {
  @apply px-4 py-2 bg-blue-500;
}

/* ✅ 推荐在计算属性中组合原子类 */
.button {
  /* 直接使用原子类或在模板中动态计算 */
}
```

```typescript
// ✅ 在组件中动态计算样式类
const buttonClasses = computed(() => ['px-4', 'py-2', 'bg-blue-500', 'hover:bg-blue-600'].join(' '))
```

## 🎯 Vue组件结构

### 组件结构

```typescript
<script setup lang="ts">
// 1. 导入和类型
import { computed, ref } from 'vue'

export interface ComponentProps {
  variant?: 'primary' | 'secondary'
  disabled?: boolean
}

// 2. Props和事件
const props = withDefaults(defineProps<ComponentProps>(), {
  variant: 'primary',
  disabled: false,
})

const emit = defineEmits<{
  'update:modelValue': [value: string]
  'click': [event: Event]
}>()

// 3. 响应式状态和计算属性
const isActive = ref(false)
const classes = computed(() => /* ... */)

// 4. 方法
function handleClick(event: Event) {
  if (props.disabled) return
  emit('click', event)
}
</script>
```

## 🎨 样式规范

### 样式计算

```typescript
const classes = computed(() => {
  const base = ['flex', 'items-center', 'rounded', 'transition-all']

  // 变体样式
  const variants = {
    primary: 'bg-primary-600 text-white',
    secondary: 'bg-gray-100 text-gray-700'
  }

  return [...base, variants[props.variant], props.disabled && 'opacity-50 cursor-not-allowed']
    .filter(Boolean)
    .join(' ')
})
```

### 样式约定

- **UnoCSS原子类** - 优先使用原子类，禁用`@apply`指令
- **响应式前缀** - `sm:`, `md:`, `lg:`
- **状态前缀** - `hover:`, `focus:`, `active:`
- **动态计算** - 在Vue计算属性中组合样式类

## 📤 事件处理

### 事件定义

```typescript
const emit = defineEmits<{
  'update:modelValue': [value: string]
  click: [event: Event]
  change: [event: Event]
}>()
```

### 事件处理

```typescript
function handleClick(event: Event) {
  if (props.disabled) return
  emit('click', event)
}

function handleKeydown(event: KeyboardEvent) {
  if (event.key === 'Enter' || event.key === ' ') {
    event.preventDefault()
    handleClick(event)
  }
}
```

### 核心原则

1. **单一职责** - 每个组件专注一个功能
2. **类型安全** - 完整的TypeScript类型定义
3. **可访问性** - 支持键盘导航和ARIA属性
4. **性能优先** - 使用computed缓存计算

### 编码规范

```typescript
// ✅ 推荐
const classes = computed(() => [...baseClasses, variantClass])
const handleClick = (e: Event) => emit('click', e)

// ❌ 避免使用 @apply 指令
// .my-button { @apply px-4 py-2 bg-blue-500; }
```

### 组件暴露

```typescript
defineExpose({
  focus: () => inputRef.value?.focus(),
  reset: () => emit('update:modelValue', '')
})
```
